01 — ABOUT

From Java Script
to Game

This project started as a Java console application — a fully functional pizza shop ordering system with OOP principles, a checkout flow, and input validation.

I then translated the entire logic into a pixel-art browser game, keeping the same ordering rules, pricing, and flow — just now playable by anyone, anywhere.

The game features animated sprite characters, scene transitions, a real bill system, and change calculation — all matching the original Java code exactly.

TECH STACK
  • Java (OOP) Pizza, Order, Checkout, PizzaShop classes — full console app
  • HTML5 + CSS3 Pixel-art scenes, animations, speech bubbles, overlays
  • Vanilla JavaScript Game state, dialogue engine, cart logic, payment flow
  • Pixel Art Assets Custom sprites, backgrounds, GIF characters, menus
